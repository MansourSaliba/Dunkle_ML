# Datasets

This project uses two types of datasets: **synthetic** (public) and **experimental** (restricted).

## Synthetic Data

- **Source**: Generated by `scripts/dunkle_forward_model.py`
- **Location**: `data/processed/dunkle_clean.csv`, `data/processed/dunkle_noisy.csv`
- **Access**: Public — included in repository
- **Description**: Physics-based synthetic thermal data for single-slope solar still using Dunkle's (1961) model with Beirut May conditions
- **Use**: For ML training, validation, and testing

### Regenerating Synthetic Data

```bash
python scripts/dunkle_forward_model.py
```

## Access Policy

- **Public data** (synthetic): Fully available in repository
- **Restricted data** (experimental): Not versioned in Git; available by direct contact
- **Reasoning**: Experimental data may contain proprietary or sensitive information
